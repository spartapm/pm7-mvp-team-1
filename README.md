# 오늘의집 MVP · 상품 상세정보 AI 탐색 개선

목적형 사용자가 상품 상세페이지에서 **상세정보 탭 · 호버 메뉴**로 사이즈·색상 등 핵심 정보에 바로 도달하도록 하는 MVP입니다.

## 실행

```bash
npm install
npm run dev
```

브라우저에서 [http://localhost:3701](http://localhost:3701) 을 엽니다.

## MVP 범위

| 화면 | 구현 |
| --- | --- |
| 카테고리(PLP) | 대분류 2개(침대, 매트리스·토퍼) · 소분류 5개 · 소분류당 상품 5개(총 25개) |
| 상품 상세(PDP) | sticky 탭바, 상세정보 호버 메뉴, 자동 스크롤(instant), 상품정보고시 AI 보강 |
| 미구현 | 리뷰/문의/배송·환불/추천 탭 동작, 장바구니·구매 기능, 정렬·필터 |

## 핵심 플로우

1. `/store/category` 에서 소분류 선택 → 상품 카드 클릭
2. PDP 상단 **상세정보** 탭에 마우스를 올리면 호버 메뉴(색상/크기/주요 소재/구성품/배송·설치비용) 노출
3. 항목 클릭 시 AI 매핑 좌표로 **instant 스크롤** (위치 2개 이상이면 드롭다운)
4. 상세정보 탭 클릭 시 **상품정보고시**로 이동 (AI 추출 배지·안내 문구 포함)

## 문서

- `docs/` — PRD, 기능명세서, 참고 스크린샷

## 데이터

현재는 명세서 JSON 스키마(`imageInfoTags`, `productInfoDisclosure`)에 맞춘 **mock 데이터 25개**를 사용합니다.  
실제 데이터셋(Drive)을 `public/products/` 등에 넣으면 같은 스키마로 교체할 수 있습니다.
